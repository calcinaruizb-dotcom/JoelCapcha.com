# Servicios Académicos

## Descripción
Esta página web presenta los servicios académicos de una institución y permite que una persona complete un formulario de registro.

## Objetivo
Mostrar los servicios de forma clara y facilitar el registro de personas interesadas.

## Archivos
- `index.html`: contiene el texto, los servicios y el formulario.
- `estilos.css`: agrega los colores y organiza el diseño.
- `script.js`: muestra un mensaje cuando se envía el formulario.
- `README.md`: explica el proyecto.

## Tecnologías
- HTML: estructura de la página.
- CSS: diseño y colores.
- JavaScript: función del formulario.

## Cómo abrir
1. Abre la carpeta en Visual Studio Code.
2. Busca el archivo `index.html`.
3. Ábrelo en tu navegador.
4. Completa el formulario para probarlo.

## Nota
Este formulario es una demostración. Muestra un mensaje, pero no guarda los datos en una base de datos.
